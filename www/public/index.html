What is a web server ?

The engine behind every website

A web server is a program that listens on a network port, accepts incoming connections from clients (browsers, curl), reads their HTTP requests, and sends back HTTP responses — HTML pages, images, JSON, or any other content. Every website you visit is served by this type of server.

Inside Webserv

Webserv runs on a single thread. Instead of spawning one thread per client, it uses poll() to monitor all file descriptors simultaneously — sockets, CGI pipes, and listeners — without ever blocking the process. Hover over each component to learn more.

HTTP

The main HTTP methods

Webserv supports the three main HTTP methods: GET, POST, and DELETE. Together, they cover the most common actions on a resource: reading, sending, and removing data.

GET
Fetch a resource
Requests a resource from the server. Read-only — a GET request must never modify data. Used for HTML pages, images, CSS, and any static content.
GET /index.html HTTP/1.1
Host: localhost:8080

← 200 OK
Content-Type: text/html
POST
Send data
Sends data to the server to create a resource. Used for file uploads (multipart/form-data), form submissions, and CGI script input via stdin.
POST /uploads HTTP/1.1
Content-Type: multipart/form-data

← 201 Created
Location: /uploads/file.txt
DELETE
Remove a resource
The server verifies path traversal safety by rejecting any URI containing ".." sequences, then checks file permissions via access() before calling unlink() on the target file.
DELETE /uploads/file.txt HTTP/1.1
Host: localhost:8080

← 204 No Content
